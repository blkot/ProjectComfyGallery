## 打开设计稿

直接用浏览器打开 `index.html`。文件自包含，无需联网、安装依赖或启动后端。

可操作：图库 / 收藏 / 搜索、筛选与排序、打开图片 / 视频封面、前后切换、胶片条、收藏、废纸篓与恢复、多选批量收藏、批量移到废纸篓、信息面板、连接示意、浅深色切换和离线预览。

外观：点右上角图标 → 外观。筛选：点“全部媒体 · 最近添加”。搜索演示词：海、山、云、岩石。

视频界面只演示播放按钮、进度与静音状态，使用静态封面；它不是真实视频播放器。所有修改只影响内存示例，不会写入后端。页面刷新后重置。示例数量由当前数据计算。

示例图来自本机 macOS 桌面壁纸缩略图（Apple），仅用于本地设计评审，不作为应用发行资源；不包含用户图库。正式实现必须替换为经过认证的服务器媒体。不得把这组示例资源打包进 iOS 应用或作为产品素材分发。

重新构建：

```sh
node mobile/design/photos-v1/build.mjs
```

构建脚本优先复用已生成的 `assets/sample-*.jpg`。重新生成示例需要 macOS 自带缩略图与 `sips`；Lucide 来自本机 Codex 依赖包，可用 `COMFY_DESIGN_NODE_MODULES` 指定包根目录。最终 `index.html` 不依赖这些路径。

## 产品决策

1. 首次连接成功后直接进入图库。核心循环为“浏览 → 筛选 → 查看 → 收藏 / 整理 → 返回原位置”。
2. 底部三个入口：图库、收藏、搜索。收藏是 `favorite=true` 的动态结果，不新建收藏数据库。设置放在右上角图标内。
3. 默认三列 **3:4 竖向缩略图（宽:高）**，即用户指定的 portrait 4:3。边缘铺满，间距 2pt，无卡片边框、阴影或每项元数据。列数随屏幕与字体自适应。
4. 按当前排序字段的日期分组。默认最近添加在前；提供创建时间从新到旧 / 从旧到新。日期是添加 / 文件创建时间，不能标成拍摄时间；无可靠日期归入“日期未知”。
5. 网格可裁切；查看器始终先完整显示原始比例。视频只显示时长；收藏显示小心形；不在每个单元格堆叠一排操作。
6. 筛选在一个系统底部面板内完成；修改是草稿，点“显示结果”才提交，关闭不改变范围。已生效条件以一行摘要显示，可清除。
7. 查看器黑底，内容区域和控制区分离。下方相邻缩略图只属于当前筛选范围。单击隐藏工具，横滑前后查看，下滑返回，图片双击 / 双指缩放。
8. 收藏、废纸篓、评价都不导致自动跳到下一项。废纸篓为可恢复状态，不命名为“永久删除”或“30 天后删除”。
9. 多选是一种临时模式。第一阶段批量收藏 / 移入废纸篓即可；默认选择已展示项目，绝不把“全选”默默扩大为全库。
10. 评价、输入媒体、空间视频生成和工作流将在后续详情面板扩展。第一阶段不放不可用按钮或空白 Tab。

用户明确要求重做，因此本轮不沿用旧文档的三 Tab（Library / Review / Settings）、默认 2:3 卡片及评价优先顺序。旧盲评边界仍适用于未来的独立盲评流程；普通图库搜索可以使用已有前端的关键词搜索。第一阶段不引入新后端行为。

## 第一阶段范围

| 核心能力 | iOS 交互 | 已有契约 / 实现依据 |
| --- | --- | --- |
| 连接与鉴权 | 地址 + 设备 Token；验证后进入图库 | `/health/live`、`/api/v1/auth/session`；Keychain 保存凭证 |
| 浏览图片与视频 | 连续滚动网格，缩略图先出现，渐进加载 | `GET /api/v1/media`，服务器分页；`preview_url` |
| 类型 | 全部 / 图片 / 视频 | `kind` |
| 收藏 | 收藏入口；筛选已收藏 / 未收藏；查看器单项切换 | `favorite`；`PATCH /api/v1/media/{id}/favorite` |
| 搜索 | 独立搜索入口；保留筛选上下文 | 列表 `q`，前端提示词 / Checkpoint / LoRA 搜索 |
| 排序 | 最近添加、创建时间新→旧 / 旧→新 | `imported_desc`、`file_created_desc`、`file_created_asc` |
| 内容分级 | 更多筛选中的不限 / SFW / NSFW | `content_rating`；不篡改已有媒体分级 |
| 废纸篓 | 不显示 / 包含 / 仅废纸篓；可恢复 | `trash=false` / 省略 / `trash=true`，现有 mutation |
| 范围内翻页 | 横滑、上一项 / 下一项、邻近缩略图 | `GET /api/v1/media/{id}/navigation` 带同一查询范围 |
| 图片 / 视频查看 | 图片缩放，系统播放器，离开暂停 | 认证后的 `original_url` / `playback_url` |
| 批量操作 | 多选工具栏，提交前显示数量 | 前端 `library-selection.ts`、bulk favorite / trash 契约 |

上表是设计到现有行为的映射，落地时以当前 API 代码为准。旧 `mobile/api-contract.md` 未包含全部最新字段，不应据此另造客户端字段。

## 屏幕与状态

- **图库**：品牌小字、大标题、连接入口；紧凑筛选摘要 + 选择；日期标题、媒体网格；图库 / 收藏 / 搜索导航。
- **筛选**：媒体类型、收藏、排序、废纸篓、内容分级。进一步的模型多选、工作流状态、集合管理不进入第一阶段。
- **查看器**：返回、日期和位置；完整媒体；视频控制；胶片条；上一项、收藏、信息、废纸篓、下一项。
- **多选**：标题显示已选数；圆形勾选；底部全选已加载、收藏、废纸篓。批量废纸篓确认，成功后可恢复。真实失败按服务端结果说明，不能假装全成功。
- **搜索**：搜索框占据标题下面的区域，结果沿用同一网格。原型仅按示例场景名匹配，不模拟真正的模型 / 提示词检索。
- **空结果**：显示“没有符合条件的媒体”，保留范围摘要，提供清除操作。
- **空库**：说明去网页导入，不显示虚构的照片数量。
- **离线有缓存**：保留预览，显示“当前离线”；未实现可靠 outbox 前禁用服务端写入；已缓存原始资源可查看，只有预览时明确“原始媒体暂不可用”。
- **离线无缓存 / 首屏错误**：连接说明与重试；不会伪装成空库。
- **分页错误**：现有网格保留，底部重试；不清空已加载媒体。
- **鉴权失败**：返回重新连接，保留浏览锚点。

## 关键行为约束

- 浏览 scope 包含搜索词、类型、收藏、废纸篓、分级、排序。查看器导航和预取都必须使用同一 scope。
- 从第 A 项进入、浏览到 B 项后返回，要定位 B；B 因取消收藏 / 移入废纸篓退出 scope 时，回到最近的仍有效邻居。ID 而非数组下标作为锚点。
- 在查看器里改变收藏 / 废纸篓后继续显示当前媒体，保留显式前后导航；下一次导航需重新确认服务端范围。原型暂时固定进入时的 ID 列表，仅验证手感。
- 滚动接近底部才拉取下一页，取消过期筛选请求，按 ID 去重。下拉刷新合并新数据并保留可见锚点。
- 图片预览按显示像素尺寸降采样；只给当前项和少量邻居高优先级；视频全局仅一个活动播放器，离开和后台时暂停。
- 44pt 触控区域；Dynamic Type；VoiceOver 宣读类型、位置、收藏状态；减少动态效果时用弱化过渡；减少透明度时使用实色材质。
- iPad 使用自适应更多列与系统侧栏，可继续复用同一 scope、查看器和连接状态；这轮精绘以 iPhone 为主。

## 实施顺序与验收

1. **连接 + 图库骨架**：连接真实测试服务，返回真实数量，混合图片 / 视频，分页和错误态可用。
2. **浏览状态**：类型、收藏、搜索、排序查询正确；快速切换不会出现旧请求结果；进入返回保留位置。
3. **查看器**：原比例、缩放、视频真实播放、同范围导航跨分页、离开暂停。
4. **整理与恢复**：单项 / 批量收藏、废纸篓、失败回滚、多端刷新一致。
5. **设备验收**：真实 iPhone 与 iPad 布局、浅深色、最大字体、网络断开、5000+ 媒体滚动内存峰值。

这些是实施验收条件，不是已经通过的集成测试。本轮已修改 Swift 文件和 Xcode 工程，但没有修改后端、Web 或 XR。模拟器与真实服务端验收尚未完成。
